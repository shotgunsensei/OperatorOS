## Migration and rollback

Imports are keyed by pinned source ID, source hash, and immutable content hash. Re-import reuses the existing challenge and content version. A changed authored definition appends a new immutable version and publishes that version; prior sessions remain pinned to prior content. Rollback selects a prior immutable version rather than mutating historical challenge content.
