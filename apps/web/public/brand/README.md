# OperatorOS brand assets

`operatoros-logo.png` is the exact source logo supplied for operatoros.net.
`operatoros-mark.png` is the transparent, text-free command-ring emblem derived
from that source for compact website and application contexts.

Usage rules:

- Use the text-free mark for favicons, install icons, badges, loaders, compact
  navigation, and other places where the wordmark cannot remain readable.
- Use the shared `OperatorLogo` component for normal horizontal site and app
  chrome so the emblem, metallic wordmark treatment, and `.net` signature stay
  consistent and accessible.
- Use the full source lockup only at a size where `OperatorOS` and `.net` remain
  readable, such as the marketing hero or social artwork.
- Do not add module names, credentials, tenant details, or other text inside
  the canonical logo assets.
