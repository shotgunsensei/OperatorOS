## Architecture and safety evidence

- OperatorOS remains the sole identity, tenant, role, entitlement, billing, secret, provider, shared AI, media, scheduler, export, usage, and audit authority. Every authenticated query includes the server-derived tenant predicate.
- Private garage records and diagnostic context are not projected into public community content. Public share links store only SHA-256 token hashes, expire/revoke durably, and return bounded projections without VINs, tenant IDs, private costs, credentials, or owner identifiers.
- Media is stored through shared attachments with content hashes, deduplication, scanning, retention, and audited download authority. Public publication requires a clean scan.
- Live bay uses a durable reconnecting sync transport rather than claiming WebSocket delivery: two-second cursored reads recover missed messages; sequence assignment is transactional; client message IDs are idempotent.
- PWA handling never caches POST bodies or authenticated HTML/data. Offline navigation receives a static reconnect-safe shell and truthfully waits for server confirmation before forms are treated as saved.
