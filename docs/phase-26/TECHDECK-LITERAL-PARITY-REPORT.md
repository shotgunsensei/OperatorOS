## Product and security decisions

- OperatorOS remains the only account, session, tenant, role, entitlement, and billing authority. TechDeck consumes those boundaries; it does not issue a second production login or subscription state.
- Shared Directory owns client, site, and contact identity. TechDeck stores scoped operational relationships to Directory IDs.
- Secret-dependent workflows store encrypted shared secret references. License keys, API tokens, public intake tokens, device fingerprints, uploader email/IP data, and webhook credentials are hash-only or encrypted at rest; raw issue values are returned once.
- Recurrence uses the shared durable scheduler. Outbound webhooks use credential-free HTTPS validation, SSRF defense, HMAC signatures, bounded retries, dead-letter state, and delivery logs.
- Anonymous intake is opaque-token, rate-limited, password-capable, type/size validated, scan-queued, hashed, deduplicated, retention-bound, and audited.
- The imported IT Ops surface is restored as reviewed documentation guidance. The pinned source does not establish a signed runner execution outcome, so Phase 26 does not invent arbitrary execution inside the web/API process.
- Business invoicing and plan changes resolve through TradeFlowKit and OperatorOS entitlements. The source user outcome remains available without duplicating billing authority inside TechDeck.
