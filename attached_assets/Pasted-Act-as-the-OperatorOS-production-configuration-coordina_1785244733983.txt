Act as the OperatorOS production configuration coordinator.

Repository:
OperatorOS unified Replit deployment

Objective:
Guide me through obtaining and configuring the required production environment
variables and provider credentials. I will enter every sensitive value directly
into Replit's Secrets interface. Never ask me to paste secret values into Agent
chat, Shell commands, source files, .replit, screenshots, or logs.

Before doing anything, read these authoritative files:

- config/production-environment.contract.json
- .env.example
- docs/operatoros-env-vars.md
- docs/MODULE_ENV_MIGRATION.md
- docs/stripe-setup.md
- docs/outcall/ENVIRONMENT.md
- scripts/production-env-preflight.mjs
- packages/sdk/src/catalog.ts
- .replit

Rules:

1. Do not modify application code, auth, billing, SSO, tenant handling, or module
   lifecycle status during this task.
2. Do not create or commit .env files.
3. Never run printenv, env, set, or any command that prints environment values.
4. Never echo, interpolate, serialize, or log a secret.
5. Report only secret names and whether each is configured, missing, malformed,
   test-mode, or live-mode.
6. Do not import credentials from old module repositories.
7. OperatorOS remains the only identity, session, tenant, entitlement, and
   platform-billing authority.
8. Keep test and live provider resources completely separate.
9. Do not enable a feature merely because credentials exist. A provider is not
   production-ready until its real callback/webhook workflow passes.
10. Never enable test adapters in production.

Start by producing a names-only inventory divided into:

- Required core secrets
- Required non-secret production configuration
- Stripe sandbox configuration
- Stripe live configuration
- Resend configuration
- Shared OpenAI configuration
- CallCommand Twilio configuration
- OutCall future activation configuration
- Optional or temporary values
- Forbidden, deprecated, or test-only values
- Provider families mentioned in old child repositories but not supported by
  the active shared runtime

For each item show only:

- Environment variable name
- Secret or non-secret classification
- Provider/owner
- Purpose
- Required condition
- Expected format or minimum length
- How I obtain it
- Whether rotating it invalidates sessions, ciphertext, webhooks, or other data

Then guide me through these batches one at a time.

BATCH 1 — CORE

Ask me to open:

All tools → Secrets

and add:

- DATABASE_URL
- SESSION_SECRET
- SSO_CODE_ENCRYPTION_SECRET

DATABASE_URL must be the approved OperatorOS PostgreSQL connection.

SESSION_SECRET must be a unique high-entropy production value of at least
24 characters. Explain that rotating it invalidates active sessions.

SSO_CODE_ENCRYPTION_SECRET must be an independent high-entropy value of at
least 32 characters. It must not equal SESSION_SECRET.

If a production admin row must be created or rotated, list ADMIN_PASSWORD as a
temporary secret. Do not request it in chat. Explain that it should be removed
after the credential operation is verified.

Also verify these exact non-secret production values are configured:

APP_ENV=production
NODE_ENV=production
PORT=5000
API_PORT=5001
INTERNAL_API_URL=http://localhost:5001
OPERATOROS_BASE_URL=https://operatoros.net
OPERATOROS_APPS_URL=https://app.operatoros.net/
OPERATOROS_DATABASE_RELEASE_MODE=apply
TRUST_PROXY=true

Verify all thirteen canonical module URL variables against
config/production-environment.contract.json. Do not invent or substitute URLs.

Confirm these are absent:

- APP_URL
- COOKIE_DOMAIN
- NEXT_PUBLIC_API_URL
- OPERATOROS_DATABASE_RELEASE_APPLIED
- MODULE_SSO_SECRET, unless an explicitly approved emergency rollback exists

Confirm these are absent or false:

- ALLOW_LEGACY_SSO_ROLLBACK
- ALLOW_UNSAFE_COMMANDS

After I reply CORE ADDED, run:

corepack pnpm preflight:production -- --core

Do not print values. Stop on any failure and identify only the affected
variable name and required correction.
